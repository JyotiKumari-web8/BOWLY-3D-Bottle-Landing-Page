# Bolly™ — 3D Interactive Dandruff-Defense Shampoo Landing Page

An interactive 3D e-commerce landing page built with **Three.js**, **Vanilla JavaScript**, and **Modern CSS**. Features real-time 3D bottle customization, multi-scent switching, interactive annotation hotspots, a cart drawer, clinical results, ingredient science breakdowns, and a smooth simulated checkout.

---

## ✨ Features

- **Interactive 3D Three.js Bottle Experience**:
  - Realistic PBR materials (`MeshPhysicalMaterial`) with clearcoat, transmission, and roughness.
  - Organic lathe geometry for realistic bottle curves and pump spout dispenser.
  - Dynamic in-memory Canvas label generator that updates in real-time.
  - 360° mouse & touch inertia dragging with physics dampening.
  - Floating ambient skincare micro-bubble particle system.
  - Interactive 3D hotspots for the Precision Pump, Bio-Active Formula, and Ocean-Bound Recycled Plastic.
  - One-click camera reset button.

- **Multi-Variant Scent & Bottle Switcher**:
  - 🟣 **Clarify Violet** (*French Lavender & White Tea*)
  - 🟢 **Fresh Mint** (*Wild Eucalyptus & Tea Tree*)
  - 🟠 **Argan Glow** (*Golden Amber & Warm Honeycomb*)
  - 🌸 **Rose Blossom** (*Damask Rose & Crisp Peony*)
  - Transitions bottle tint, rim lighting color, label textures, aroma profile cards, and CSS theme accents on the fly.

- **Complete E-Commerce Flow**:
  - Slide-in cart drawer with live subtotal and quantity controls.
  - Dynamic **Free Shipping Progress Bar** with real-time threshold calculations ($40).
  - Promo code system: Apply **`FRESH15`** for an instant 15% discount.
  - Instant live search overlay with auto-suggestions and quick tags.
  - Complete simulated checkout modal and order confirmation celebration screen.

- **High-Converting Landing Page Sections**:
  - Top announcement banner.
  - Glassmorphic sticky header with smooth scrolling.
  - Trust & benefits bar with 4-column value proposition.
  - Bio-Active Ingredient Science Explorer.
  - Independent clinical trial metrics grid.
  - 3-Step hair washing routine ritual.
  - Bolly vs. Traditional Shampoos comparison matrix.
  - Verified customer reviews & rating breakdown.
  - Expandable FAQ accordion.
  - VIP Scalp Club newsletter discount unlock.
  - Luxury footer with brand guarantees.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES6+), CSS3 (Custom Properties & Glassmorphism)
- **3D Graphics Engine**: [Three.js (r128)](https://threejs.org/)
- **Server**: Lightweight Node.js HTTP static server
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Playfair Display*)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher)

### Installation & Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/JyotiKumari-web8/BOWLY-3D-Bottle-Landing-Page.git
   cd BOWLY-3D-Bottle-Landing-Page
   ```

2. Start the local server:
   ```bash
   npm start
   # or
   node server.js
   ```

3. Open your browser and navigate to:
   ```text
   http://localhost:8080
   ```
